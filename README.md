# SecureAuth 🔐

SecureAuth is a simple authentication system built as a learning and portfolio project. It allows users to register, log in, manage their session, and access a protected dashboard based on their selected role.

## 🚀 Features

* User registration
* User login
* Logout functionality
* Password strength indicator
* Password confirmation validation
* Email validation
* Role selection
* Session management using localStorage
* Protected dashboard
* Responsive authentication interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* Browser Local Storage

## 👤 User Roles

Users can register with one of the following roles:

* Employee
* Learner
* Supervisor
* Admin

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/MoriswiSimon/SecureAuth.git
```

2. Open the project in Visual Studio Code.

3. Open `index.html` in your browser.

4. Register an account and log in.

## 🔐 Security Note

This project is intended for learning and portfolio purposes. User passwords are currently stored in browser localStorage and are **not suitable for production use**.

A production authentication system should use a backend server, secure password hashing, HTTPS, secure sessions/tokens, and a database.
